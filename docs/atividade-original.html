Início HTML Semântico Benefícios

O que é HTML Semântico?

HTML semântico é o uso de elementos que possuem significado sobre o conteúdo de uma página.

Em vez de utilizar apenas elementos genéricos, podemos usar tags como header, main, article, section e footer para indicar claramente a função de cada parte do site.

Por que utilizar HTML Semântico?

  • Acessibilidade

    Facilita a interpretação da página por leitores de tela e outras tecnologias assistivas.

  • SEO

    Ajuda mecanismos de busca a compreender melhor a estrutura e o conteúdo da página.

  • Manutenção

    Torna o código mais organizado, legível e fácil de manter.
