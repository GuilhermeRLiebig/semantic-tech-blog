CONCEITO

O que é HTML Semântico?

HTML não serve apenas para posicionar conteúdo. Seus elementos também podem descrever o significado de cada parte da página.

HTML semântico utiliza elementos que indicam claramente a função do conteúdo dentro de uma página.

Em vez de utilizar apenas elementos genéricos como <div>, podemos utilizar elementos específicos como <header>, <nav>, <main>, <article>, <section>, <figure> e <footer>.

BENEFÍCIOS

Por que utilizar HTML semântico?

Uma boa estrutura melhora tanto a experiência de desenvolvimento quanto a utilização da página.

Acessibilidade

Facilita a interpretação da página por leitores de tela e outras tecnologias assistivas.

SEO

Ajuda mecanismos de busca a compreender melhor a organização e o significado do conteúdo.

Manutenção

Deixa o código mais organizado, legível e fácil de modificar no futuro.

ESTRUTURA

Anatomia de uma página semântica

Uma página pode ser dividida em regiões que possuem funções específicas.

REFERÊNCIA

Principais tags semânticas

Algumas das tags mais importantes para organizar uma página HTML.

<header>

Cabeçalho da página ou de uma seção.

<nav>

Área destinada à navegação.

<main>

Conteúdo principal da página.

<article>

Conteúdo independente e completo.

<section>

Agrupa conteúdos relacionados.

<figure>

Representa conteúdo ilustrativo.

<aside>

Conteúdo complementar.

<footer>

Rodapé da página ou seção.

TAG SELECIONADA

<header>

Representa o cabeçalho de uma página ou seção.

Quando utilizar?

Utilize para títulos, logotipos, introduções e outros elementos relacionados ao cabeçalho.

Exemplo HTML 
<header>
    <h1>Meu site</h1>
</header>
NA PRÁTICA

Uma página semântica completa

Veja como diferentes elementos semânticos podem trabalhar juntos.

index.html 
<body>

    <header>

        <h1>Meu Blog</h1>

        <nav>
            <a href="#inicio">Início</a>
        </nav>

    </header>


    <main>

        <article>

            <h2>HTML Semântico</h2>

            <section>

                <p>
                    Conteúdo do artigo.
                </p>

            </section>


            <figure>

                <img
                    src="imagem.jpg"
                    alt="Exemplo"
                >

                <figcaption>
                    Exemplo ilustrativo
                </figcaption>

            </figure>

        </article>

    </main>


    <footer>

        <p>
            Meu site
        </p>

    </footer>

</body>
